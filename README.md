# Renault Logan · OBD-II Scanner

Веб-приложение для диагностики Renault Logan через ELM327 BLE
и ведения журнала технического обслуживания.

## Возможности

- 🔌 Подключение к ELM327 по Web Bluetooth (BLE 4.0)
- 📊 Живые параметры: обороты, скорость, температура ОЖ, напряжение и др.
- 📈 Графики в реальном времени + пресеты (АКБ / прогрев / разгон)
- ⚠️ Алерты: перегрев ОЖ, низкое напряжение АКБ (звук + цвет)
- 🩺 Чтение и стирание кодов ошибок (DTC)
- 📋 Журнал ТО: 44 позиции, 5 двигателей Logan, напоминания
- 🚗 Мульти-профили по VIN / госномеру (несколько машин в семье)
- 💾 Экспорт / импорт JSON, авторезерв в localStorage

## Требования

- Браузер: **Chrome или Edge** (Web Bluetooth)
- ОС: Windows, macOS, Linux, **Android** (iOS не поддерживает Web Bluetooth)
- Адаптер: **ELM327 BLE 4.0** (не классический Bluetooth!)
  - Vgate iCar Pro BLE 4.0
  - Viecar BLE 4.0
  - Vgate vLinker BM+ BLE
  - OBDLink MX+
# Поддерживаемые BLE-адаптеры для Renault Logan

<details>
<summary><strong>Показать список поддерживаемых моделей</strong></summary>

- **Vgate vLinker MC+ (Bluetooth 4.0 BLE)**  
  Оптимальный выбор по соотношению цены и возможностей для Renault. Поддерживает буфер до 2048 байт, корректно работает с K-Line на Logan I и с CAN-шиной на Logan II/III.

- **Vgate iCar Pro 2S (Bluetooth 5.2 BLE)**  
  Хороший бюджетный вариант на оригинальном чипе. Стабильно держит BLE-связь, понимает команды инициализации Renault, но медленнее серии vLinker при массовом опросе датчиков.

- **Vgate iCar Pro BLE 4.0**  
  Бюджетный BLE-адаптер. Подходит для базовой диагностики Renault, но уступает vLinker по скорости и стабильности на длинных ответах.

- **Viecar ELM327 v1.5 (Bluetooth 4.0 BLE, PIC18F25K80)**  
  Самый доступный вариант, который дружит с Renault. Важно: нужна именно версия **Bluetooth 4.0 (BLE)** с чипом **PIC18F25K80**, иначе Logan I по K-Line может не прочитаться.

- **OBDLink CX (Bluetooth 5.1 BLE)**  
  Профессиональный уровень. Поддерживает все протоколы Renault без сбоев, высокая скорость передачи данных и мгновенный отклик, но заметно дороже.

- **OBDLink MX+**  
  Профессиональный адаптер с высокой скоростью и стабильностью. Подходит для глубокой диагностики Renault Logan всех поколений, но стоит дороже бюджетных моделей.
